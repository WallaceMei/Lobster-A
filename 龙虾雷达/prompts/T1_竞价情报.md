### Step 1: 扫描隔夜重大消息（近 18 小时）

并行执行 3 路搜索：

```python
# 1) 金十数据
jin10_results = web_search(
    "金十数据 [今日日期] site:jin10.com",
    time_filter="18h"
)
# 排除关键词（按 SKILL 节 1.2 DS7）: 美股/纳指/外汇/原油/比特币

# 2) 证监会 + 部委级政策
policy_results = web_search(
    "证监会 OR 国务院 OR 工信部 OR 发改委 [今日日期]",
    time_filter="18h"
)

# 3) 隔夜美股映射（科技股影响 A 股 AI/算力/半导体板块）
us_results = web_search(
    "纳指 标普 [昨夜] 涨跌 site:wallstreetcn.com OR site:cls.cn",
    time_filter="18h"
)
```

提取并归类：
- **政策类**: 部委文件 / 证监会公告
- **行业类**: 重大产业事件（如"特斯拉发布新车"、"OpenAI 发布新模型"）
- **公司类**: 业绩预告超预期 / 重大合同 / 重组复牌
- **海外类**: 隔夜美股科技股大涨/大跌（仅当涨跌幅 > 2% 才记录）

### Step 2: 拉竞价数据（9:25 后才有）

⚠️ **DSA 没有 `/api/v1/market/pre_market_quotes` 接口** — 用 AkShare 替代：

```python
import akshare as ak

# 9:25 后能拿到集合竞价数据
df = ak.stock_zh_a_spot_em()  # 全 A 股实时（含竞价）

# 高开异动筛选
high_open = df[
    (df['涨跌幅'] > 5.0) &       # 高开 > 5%
    (df['成交额'] > 1e7) &        # 竞价成交额 > 1000 万
    (~df['名称'].str.startswith('ST')) &  # 排除 ST
    (~df['名称'].str.contains('退'))      # 排除退市
].nlargest(30, '涨跌幅')         # 按涨幅取前 30
```

### Step 3: 消息-标的匹配（核心推理）

对 Step 1 的每条消息：
1. 用 DeepSeek 推断该消息利好哪些板块/标的（用 `config/stock_pool.yaml.sector_keywords` 做关键词映射）
2. 在 Step 2 的 `high_open` 名单里查这些板块的票
3. 命中规则：
   - 消息利好板块 X，且 X 板块多只（≥2）票高开 → "**消息验证成功**"
   - 消息利好板块 X，但 X 板块无票高开 → "**消息未发酵**"
   - 单只票高开但没匹配到任何消息 → "**疑似拉高出货**"

### Step 4: 红线扫描（按 SKILL 节 5）

并行扫描：
- 上交所今日公告: web_fetch "http://www.sse.com.cn/disclosure/listedinfo/announcement/"
- 深交所今日公告: web_fetch "http://www.szse.cn/disclosure/listed/notice/"
- 巨潮资讯（更全）: web_fetch "http://www.cninfo.com.cn/new/disclosure"

匹配 P0/P1 关键词清单：
- P0_即停: ["立案调查", "退市风险警示", "*ST", "重大资产重组停牌"]
- P1_警报: ["业绩预告变脸", "审计意见保留", "实控人被立案", "大规模减持公告"]

如果 Wallace 持仓股（查 `stock_pool.yaml.holdings`）触发 P0/P1 → **必须**在卡片顶部红字标出。

### Step 5: 主线题材判定

调用 SKILL 节 2.2 R2 题材炒作判定：
- 板块涨幅榜 Top 10（用 `ak.stock_board_concept_em()` 概念板块）
- 涨停 ≥ 3 家
- 三个验证维度（政策 + 事件 + 资金）

输出：今日主线题材 = [板块A] + [板块B]（最多 2 个），每个标 "确立/发酵/警惕"

### Step 6: 9:30 开盘建议生成

综合 Step 3 + Step 5：
- 选出"消息验证成功"的板块龙头股 2-3 只
- 给出激进/稳健/观望的总基调

⚠️ **不能给具体的"买入价"**（竞价完才知道开盘价），只能给"重点盯哪些票"。

### Step 7: 输出最终报告 + 写日志

把分析结果按下方 Markdown 模板生成最终输出, 直接作为本任务的最终回复。
**Qclaw 会自动把这条回复推送到 Wallace 的飞书** (无需自己 POST 任何 URL)。

同时写入 `data/dedupe.sqlite.daily_push_count` 记录今日 T1 已执行 1 次。

## 错误处理（按 SKILL 节 8.3 协议）

| 失败场景 | 应对 |
|---|---|
| AkShare 拉竞价失败（Clash 拦截） | 跳过 Step 2，仅推消息扫描 + 红线，标"⚠️ 竞价数据未取" |
| 金十 web_search 0 结果 | 改用 MiniMax 搜索，仍 0 则标"金十数据获取失败" |
| 交易所公告抓取失败 | 红线扫描跳过，标"⚠️ 红线未扫"（**关键警告**: Wallace 必须知道未做红线扫描） |
| LLM 调用失败 | 降级输出原始消息列表 + 高开名单，不做匹配 |
| 输出生成失败 | Qclaw 任务报错 → Wallace 在 Qclaw 任务模块看错误日志 (Qclaw 自动通知) |
