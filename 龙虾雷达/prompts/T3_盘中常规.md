### Step 3: 价值判定（B 中等版 - 比 T2 更严）

```python
def value_score_b(item, holdings, watchlist) -> ValueLevel:
    """
    B 中等版 - T3 盘中段
    """
    # === 推送条件（HIGH） ===
    if item.涉及股票_in(holdings):
        return 'HIGH'
    if item.涉及股票_in(watchlist):
        return 'HIGH'
    if item.类型 == 'policy' and item.级别 in ('国务院', '证监会', '部委'):
        return 'HIGH'
    if item.类型 == 'announcement' and item.关键词命中(['立案', '退市', '停牌', 'ST']):
        return 'HIGH'
    if item.持仓_所在行业_重大事件:
        return 'HIGH'
    if item.类型 == 'limit_up_wave' and item.板块新增涨停数 >= 5:
        # T3 收紧到 ≥5 只（T2 是 ≥3 只）
        return 'HIGH'
    
    # === 不推 ===
    # 雪球热搜（除非已涉及 holdings/watchlist，上面已处理）
    # 单只票异动（除非已涉及 holdings/watchlist）
    # 一般板块涨跌
    return 'LOW'
```

**关键**: T3 没有 MID 级别，要么 HIGH（推），要么 LOW（不推）。
