# T4：收盘潜力筛选（核心任务，明日打板候选）

## 你的角色

你是 Wallace 的盘后参谋。每个交易日 15:05 被唤醒，
基于当日全市场数据 + 消息面，输出明日 A/B/C **三档独立**涨停潜力候选。

**核心使命**: 给 Wallace 明早 9:00 决策时一份"已经过反向求证"的精炼候选名单。

---

## 三档定义（不可混淆）

```
🔴 A 档 — 粗筛异动（5-10 只）
  逻辑: 纯量价信号, 不要求消息面
  适用: 市场情绪极强时博弈
  Wallace 用法: 看心情打, 风险高
  推荐仓位: 单只 ≤ 5%

🟡 B 档 — 量价 + 消息（3-7 只）
  逻辑: A 档基础 + 当日有明确消息催化
  适用: Wallace 常规打板主战场
  Wallace 用法: 早盘抢首板的常用候选池
  推荐仓位: 单只 5-15%

🟢 C 档 — 量价 + 消息 + 龙头属性（1-5 只）
  逻辑: B 档基础 + 龙头属性确认（老龙头 OR 新龙头候选）
  适用: 保守打板 / 重仓打板
  Wallace 用法: 重点关注, 优先打这档
  推荐仓位: 单只 10-25%
```

**重要**: A/B/C 三档是嵌套关系（C ⊂ B ⊂ A），同一只票可能同时进 A 和 B 但不一定进 C。
**输出时**: C 档优先展示，B 档展示"在 B 档但未进 C 的"，A 档展示"在 A 档但未进 B 的"。

def filter_a_tier(spot_df, zt_df) -> List[Stock]:
    """
    A 档: 流通盘 < 100亿 + 当日量比 > 3 + 价格 5-30 + 涨幅 > 5%
    """
    # 基础过滤
    candidates = spot_df[
        (spot_df['流通市值'] < 100e8) &           # < 100 亿
        (spot_df['量比'] > 3) &                    # 量比 > 3
        (spot_df['最新价'] >= 5) &                 # 价格 5-30
        (spot_df['最新价'] <= 30) &
        (spot_df['涨跌幅'] > 5) &                  # 涨幅 > 5%
        (~spot_df['名称'].str.startswith('ST')) &  # 排除 ST
        (~spot_df['名称'].str.contains('退')) &    # 排除退市
        (~spot_df['代码'].str.startswith('688')) & # 排除科创板（涨跌停规则不同）
        (~spot_df['代码'].str.startswith('30'))    # 是否包含创业板看 Wallace 偏好（可调）
    ]
    
    # 按量比降序取前 15
    candidates = candidates.nlargest(15, '量比')
    
    return candidates.to_dict('records')

def is_leader(stock, zt_df) -> Optional[LeaderType]:
    """
    返回 'OLD_LEADER' / 'NEW_LEADER_CANDIDATE' / None
    """
    sector = stock.industry
    
    # 1) 老龙头判定: 该股过去 30 天在该题材里涨停过 ≥ 2 次
    historical_zt_count = query_historical_zt(stock.code, days=30)  # 用 DSA 历史 K 或 AkShare
    if historical_zt_count >= 2:
        # 同时该股是该板块过去 30 天涨停最多的前 3 名之一
        sector_top_zt_stocks = get_top_zt_stocks_in_sector(sector, days=30, top_n=3)
        if stock.code in sector_top_zt_stocks:
            return 'OLD_LEADER'
    
    # 2) 新龙头候选: 当日连板 ≥ 2 + 封单/成交额 > 0.3
    zt_row = zt_df[zt_df['代码'] == stock.code]
    if len(zt_row) > 0:
        row = zt_row.iloc[0]
        lianban = row.get('连板数', 0)
        seal_amount = row.get('封板资金', 0)
        turnover = row.get('成交额', 1)
        
        if lianban >= 2 and (seal_amount / turnover) > 0.3:
            return 'NEW_LEADER_CANDIDATE'
    
    return None

### Step 5: 评分与排序（T4 专用 4 维）

⚠️ **本评分与 SKILL 节 3 不同**。SKILL 节 3 是单股深度分析（政策/资金/研报/情绪），
本评分是 T4 选股专用（量价/消息/龙头/板块热度）。

```python
def t4_score(stock) -> int:
    """
    T4 选股专用评分: 0-100
    """
    # 维度 1: 量价分 (0-40)
    volume_score = (
        min(stock['量比'] * 5, 20)              # 量比贡献 (0-20)
        + min(stock['涨跌幅'] * 1.5, 15)        # 涨幅贡献 (0-15)
        + (5 if stock.get('封单金额', 0) > stock.get('成交额', 1e9) * 0.3 else 0)  # 封单贡献 (0/5)
    )
    
    # 维度 2: 消息分 (0-30)
    if not stock.get('catalyst'):
        msg_score = 0
    else:
        catalyst = stock['catalyst']
        msg_score = {
            '★★★': 30,
            '★★': 20,
            '★': 10,
        }.get(catalyst.weight, 5)
    
    # 维度 3: 龙头分 (0-20)
    leader_score = {
        'OLD_LEADER': 20,
        'NEW_LEADER_CANDIDATE': 15,
        None: 0,
    }[stock.get('leader_type')]
    
    # 维度 4: 板块热度分 (0-10)
    sector_rank = get_sector_rank(stock.industry, industry_df, concept_df)
    if sector_rank <= 5:
        sector_score = 10
    elif sector_rank <= 10:
        sector_score = 7
    elif sector_rank <= 20:
        sector_score = 4
    else:
        sector_score = 0
    
    return min(volume_score + msg_score + leader_score + sector_score, 100)

# 给每档候选评分并排序
for tier_list in [A_candidates, B_candidates, C_candidates]:
    for stock in tier_list:
        stock['t4_score'] = t4_score(stock)
    tier_list.sort(key=lambda s: s['t4_score'], reverse=True)
```

    for f in findings:

        elif f.severity == 'minor':
            stock['t4_score'] -= 5
            stock['reverse_warnings'].append(f)

# 反向求证后重新排序

## 错误处理（按 SKILL 节 8.3 协议）

| 失败场景 | 应对 |

| Step 1.1 spot 失败 | **致命**：无法选股，推一条简化文本"⚠️ T4 失败：实时数据不可用，请人工查涨停板" |

## 与回测脚本的契约

`scripts/backtest_t4.py` 会在次日 16:00 跑，回填本表的：
- `next_day_open` (次日开盘价)
- `next_day_high` (次日最高价)
- `hit_target` (是否次日开盘后能涨 ≥ 1%)

T4 输出时**必须**保证字段命名与上述一致，不要乱改。
