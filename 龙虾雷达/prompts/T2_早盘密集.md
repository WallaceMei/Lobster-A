### Step 3: 价值判定（C 宽松版）

**对每条候选信息（金十快讯 / 新增涨停 / 板块异动）评分**:

```python
def value_score(item, holdings, watchlist) -> ValueLevel:
    """
    C 宽松版价值判定 - 早盘段
    """
    # === 高价值 (HIGH) - 必推 ===
    if item.涉及股票_in(holdings):
        return 'HIGH'  # 持仓股相关 100% 推
    if item.涉及股票_in(watchlist):
        return 'HIGH'  # 盯盘池相关 100% 推
    if item.类型 == 'policy' and item.级别 in ('国务院', '证监会', '部委'):
        return 'HIGH'  # 高级政策必推
    if item.类型 == 'announcement' and item.关键词命中(['立案', '退市', '停牌', 'ST']):
        return 'HIGH'  # 交易所重大公告必推
    
    # === 中价值 (MID) - 凑批量推 ===
    if item.持仓_所在行业_重大事件:
        return 'MID'
    if item.类型 == 'limit_up_wave':
        # 涨停潮: 同板块新增涨停 ≥ 3 只 (本轮新增, 不是累计)
        if item.板块新增涨停数 >= 3:
            return 'MID'
    if item.类型 == 'xueqiu_hot':
        # 雪球 Top 5 异常拉升 (近 30 分钟评论数翻倍)
        return 'MID'
    
    # === 低价值 (LOW) - 不推 ===
    return 'LOW'
```

每轮扫描完，按 HIGH > MID > LOW 排序，仅处理 HIGH+MID。

### Step 4: 去重检查（按 SKILL 节 7 半衰期）

对每条 HIGH/MID 候选：

```python
import hashlib

def make_hash(item) -> str:
    # 标题 + 来源 + 涉及主标的
    raw = f"{item.title}|{item.source}|{item.main_target}"
    return hashlib.md5(raw.encode('utf-8')).hexdigest()[:16]

def is_duplicate(item) -> bool:
    h = make_hash(item)
    cur.execute(
        "SELECT pushed_at FROM pushed_news WHERE hash=? AND task_name IN ('T1','T2','T3')",
        (h,)
    )
    row = cur.fetchone()
    if not row:
        return False
    
    # 半衰期判定
    elapsed_minutes = (now - row[0]).total_seconds() / 60
    half_life_minutes = {
        'flash': 30,
        'short': 1440,    # 24h
        'medium': 4320,   # 3d
        'long': 10080,    # 7d
        'permanent': 999999
    }[item.half_life]
    
    return elapsed_minutes < half_life_minutes
```

| 输出生成失败 | Qclaw 任务报错, 看 Qclaw 任务日志; count 不 +1 |
