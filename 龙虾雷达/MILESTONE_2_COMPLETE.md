## 3. 重大补充（v4.0 新增，文档原版没有）

### 3.1 DSA 接口现实矫正
- 文档里假设的 `/api/v1/market/*` 系列接口**不存在**
- 在数据源表中**全部用 AkShare 替代**:
  - 涨停板 → `ak.stock_zt_pool_em()`
  - 龙虎榜 → `ak.stock_lhb_detail_em()`
  - 板块涨幅 → `ak.stock_board_industry_summary_ths()` + `ak.stock_board_concept_em()`
  - 连板梯队 → 用涨停板池的"连板数"字段排序
  - 集合竞价 → `ak.stock_zh_a_spot_em()` 9:25 后调用
- DSA 仅保留 `/analysis/analyze`（深度分析）和 `/stocks/{code}/quote`（快速报价）

### 3.2 代理处理协议
- Wallace 电脑装了 Clash（127.0.0.1:9567），系统级代理被 Python requests 自动读
- 协议: 每次调用 AkShare 或国内站点前必须设 `NO_PROXY=*` + 用 `Session(trust_env=False)`
- DSA API 不受影响（DSA 自己处理过）

### 3.3 错误处理总入口
- 写了完整的 `execute_with_safety()` 总入口伪码
- 任何单一数据源失败都不能让 SKILL 崩溃
- 输出永远成功，降级模式必须显式标 `degraded=true`

### 3.4 调用契约
- 完整的 TypeScript 风格 Input/Output Schema
- T1-T5 必须按此契约调用 SKILL，避免歧义

### 3.5 龙虎榜游资白名单
- 列了 6 个顶级游资席位（拉萨天团 / 八大金刚 / 炒股养家 / 赵老哥附近席位 / 绍兴帮）
- 命中即评分加分，作为 T4 候选股的额外信号
