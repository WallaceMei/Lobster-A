## 1. 故障分级

| 级别 | 含义 | 行动 |
|---|---|---|
| 🔴 P0 致命 | 整个系统不工作（飞书无任何推送 / DSA 完全挂掉） | 立即修复，可能要回滚 |
| 🟠 P1 严重 | 单个任务全天失败（如 T4 没出候选） | 当天修复 |
| 🟡 P2 中等 | 偶发失败 / 个别字段异常 | 1-2 天内修复 |
| 🟢 P3 轻微 | 推送内容质量问题（如评分偏差） | 周末统一调整规则 |

### 问题 3: T4 没出候选 / 报"无满足条件标的"

**可能原因**:
- 当日是周末 / 节假日 (AkShare 涨停板池返回空)
- 当日大盘极弱（涨停 < 10 只）
- A 档筛选条件太严

**排查步骤**:
```python
# 在 Python 里手动跑 T4 Step 2 看看
import os
os.environ['NO_PROXY'] = '*'
import akshare as ak

today = '20260424'  # 改成你要查的日期
zt_df = ak.stock_zt_pool_em(date=today)
print(f"今日涨停 {len(zt_df)} 只")

spot_df = ak.stock_zh_a_spot_em()
filtered = spot_df[
    (spot_df['流通市值'] < 100e8) &
    (spot_df['量比'] > 3) &
    (spot_df['最新价'] >= 5) &
    (spot_df['最新价'] <= 30) &
    (spot_df['涨跌幅'] > 5)
]
print(f"A 档候选 {len(filtered)} 只")
```

如果 A 档候选 == 0 → 当日市场情绪过弱，T4 推"今日无满足条件标的"是正常行为，不算错误。

**修复**:
1. 备份: `copy data\dedupe.sqlite data\dedupe.sqlite.bak`
2. 重新初始化: `python scripts\init_dedupe_db.py`（不会删旧数据，只建表）

如果还是重复推，删掉数据库重建：
```powershell
del data\dedupe.sqlite
python scripts\init_dedupe_db.py
```

### 问题 7: DSA `python webui.py` 启动报错

**常见报错**:

| 报错 | 原因 | 修复 |
|---|---|---|
| `ModuleNotFoundError: No module named 'xxx'` | 依赖缺失 | `cd daily_stock_analysis && pip install -r requirements.txt` |
| `Address already in use` | 端口 8000 被占 | 先 `netstat -ano \| findstr :8000` 找占用进程，killtask 或用 `WEBUI_PORT=8001 python webui.py` |
| `OSError: [WinError 10049]` | host 配置错 | `WEBUI_HOST=127.0.0.1 python webui.py` |
| LLM 相关报错 | DSA 的 .env 没配 LLM key | 编辑 `daily_stock_analysis/.env` 配 DeepSeek/Gemini key |

## 4.5 已知 Qclaw 客户端 bug

**中文消息乱码**: Wallace 已发现 (2026-04-24)
- 现象: Qclaw 通过远控通道推送的中文消息在飞书显示乱码 (英文/数字/emoji 正常)
- 根因: Qclaw 客户端 Windows 中文系统下 curl.exe 用 GBK 编码, 而飞书 API 期望 UTF-8
- 状态: Wallace 已反馈 Qclaw 团队, 等修复
- **不影响架构**, 只影响显示。修好后所有过往任务的中文消息都会自动正确显示

## 4.6 应急方案: Qclaw 通道挂了怎么办

如果 Qclaw 通道完全失效 (任务跑了但飞书收不到), 用 lark-oapi 直接调飞书 API:

```python
# 应急脚本 (按需手写, 不放进生产)
import os
os.environ['NO_PROXY'] = '*'
import requests, json
from dotenv import load_dotenv
load_dotenv('config/secrets.env')

# 1. 拿 tenant_access_token
r = requests.post(
    'https://open.feishu.cn/open-apis/auth/v3/tenant_access_token/internal',
    json={'app_id': os.getenv('FEISHU_APP_ID'), 'app_secret': os.getenv('FEISHU_APP_SECRET')}
)
token = r.json()['tenant_access_token']

# 2. 发消息到 Wallace 的 open_id
open_id = os.getenv('WALLACE_FEISHU_OPEN_ID')
requests.post(
    'https://open.feishu.cn/open-apis/im/v1/messages?receive_id_type=open_id',
    headers={'Authorization': f'Bearer {token}'},
    json={
        'receive_id': open_id,
        'msg_type': 'text',
        'content': json.dumps({'text': '🦞 应急通道测试'}, ensure_ascii=False)
    }
)
```

凭据已存 `config/secrets.env`:
- `FEISHU_APP_ID` / `FEISHU_APP_SECRET`
- `WALLACE_FEISHU_OPEN_ID`
